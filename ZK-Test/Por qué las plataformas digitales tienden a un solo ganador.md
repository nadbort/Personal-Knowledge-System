# Por qué las plataformas digitales tienden a un solo ganador

Una aplicación de mensajería vale más cuantas más personas la usan: cada usuario nuevo aumenta el valor para todos los demás. Esto hace que el mercado se incline hacia una sola plataforma dominante ("el ganador se lo lleva todo").

Los competidores pueden tener mejor producto y aun así fracasar, porque no pueden ofrecer la misma audiencia. Las autoridades de competencia discuten si obligar a la interoperabilidad para romper ese bloqueo.
