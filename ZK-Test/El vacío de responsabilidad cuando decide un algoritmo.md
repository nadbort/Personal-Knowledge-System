# El vacío de responsabilidad cuando decide un algoritmo

Cuando un sistema automático niega un crédito o un subsidio, la responsabilidad se diluye: el programador dice que solo implementó los requisitos, la empresa culpa al proveedor y el empleado dice que "lo decidió el sistema".

Si nadie puede responder por una decisión, la persona afectada no tiene a quién reclamar. Toda decisión automatizada que afecte derechos debería tener un responsable humano identificable.
