# Repetición espaciada

Repasar un contenido a intervalos cada vez más largos —un día, tres días, una semana, un mes— fija la memoria mucho mejor que estudiarlo muchas veces seguidas.

Cada repaso justo antes de olvidar refuerza el recuerdo y alarga el siguiente intervalo. Aplicaciones como Anki programan esos repasos automáticamente. Se basa en la [[La curva del olvido de Ebbinghaus]].
