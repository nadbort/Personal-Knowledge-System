# Explicabilidad: derecho a entender una decisión automática

Una decisión que no se puede explicar tampoco se puede impugnar. Si un modelo rechaza una solicitud, la persona necesita saber qué factores pesaron para poder corregir un error o señalar una injusticia.

Los modelos más precisos suelen ser los menos interpretables, lo que obliga a elegir: en decisiones de alto impacto, quizás convenga sacrificar algo de precisión a cambio de poder explicar el porqué.
